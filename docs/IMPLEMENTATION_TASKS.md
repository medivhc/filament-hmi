# Filament HMI 实现任务清单（10Hz 输入 / 60Hz 渲染）

## T0. 初始化与外部依赖
- **目标**: 获取 Filament 源码作为学习参考，并建立 Android 工程骨架。
- **输入/上下文**:
  - 目标场景参考图（驾驶道路 + HUD）。
  - 要求使用 Filament Android API。
- **输出**:
  - Android 模块骨架（后续任务填充）
- **依赖**: 无。
- **验收**:
  - 可定位到 Filament Android 示例代码路径。
- **状态**: 已完成（2026-05-27，已确认 Filament 依赖路径与接入方案，不再使用仓库内 submodule）。
- **工程化补充**: 新增 `scripts/bootstrap_android_sdk.sh` 与 `scripts/test.sh`，确保本地 SDK 可复用并避免每次构建重复下载。

## T1. 场景协议定义（proto2）
- **目标**: 定义 10Hz 场景输入协议，覆盖道路、车辆、HUD、导航引导带。
- **输入/上下文**:
  - 上游每 100ms 下发一帧场景数据。
  - 车辆可占位模型，其他元素需要动态 mesh/material。
- **输出**:
  - `proto/driving_scene.proto`
  - 协议字段说明文档
- **依赖**: T0。
- **验收**:
  - `timestamp_ms`、`seq`、`ego_pose`、`vehicles`、`lane_guide`、`hud` 完整。

## T2. 渲染运行时架构（Filament Android）
- **目标**: 建立 Engine/Renderer/View/Scene 生命周期与渲染循环。
- **输入/上下文**:
  - Android `SurfaceView`。
  - Filament 渲染线程与资源释放规则。
- **输出**:
  - 渲染核心类（Lifecycle-safe）
- **依赖**: T0。
- **验收**:
  - 启动页面可渲染空场景并稳定 60Hz。
- **状态**: 进行中（2026-05-27，已完成 Android + Filament 运行时骨架、生命周期与 60Hz 调度框架）。

## T3. 10Hz->60Hz 插值/内推模块
- **状态**: 已完成（2026-05-27，已实现帧缓存、插值/内推和速度平滑模块，并补齐单元测试）。
- **目标**: 把 10Hz proto 输入平滑成 60Hz 场景状态。
- **输入/上下文**:
  - T1 定义的时间戳与姿态/速度字段。
- **输出**:
  - 帧缓存、时间同步器、车辆轨迹关联、HUD 低通滤波。
- **依赖**: T1, T2。
- **验收**:
  - 连续输入下无明显跳变；断流短时内推（<=150ms）后安全降级。

## T4. 动态 Mesh 与材质
- **状态**: 已完成（2026-05-27，已实现道路/蓝带/车辆占位 mesh 生成与运行时 scene composition 接入）。
- **目标**: 用动态 mesh + mat 生成道路、车道线、蓝色引导带。
- **输入/上下文**:
  - T3 输出的 60Hz 场景状态。
- **输出**:
  - Road/LaneGuide MeshBuilder + Material 参数更新。
- **依赖**: T2, T3。
- **验收**:
  - 场景视觉与参考图结构一致（非像素级）。


## T4.1 车辆白模高质感光照
- **目标**: 自车与其他车辆使用统一高质感白模（PBR）材质。
- **输入/上下文**:
  - T4 动态 mesh 输出。
  - 车辆可使用占位几何，但材质需具备真实光照反馈。
- **输出**:
  - 白模材质参数模板（baseColor/roughness/reflectance/clearcoat）。
  - 车辆材质绑定策略（ego 与 traffic 一致，允许局部参数差异）。
- **依赖**: T2, T4。
- **验收**:
  - 车辆在不同日照角度下高光与阴影变化自然。

## T4.2 实时日照与阴影
- **目标**: 场景实时体现日照变化与阴影（含道路与车辆投影）。
- **输入/上下文**:
  - 系统时间或外部下发日照参数。
- **输出**:
  - 动态太阳光方向/强度/色温估计器。
  - 实时阴影强度控制与软阴影参数。
- **依赖**: T2, T4。
- **验收**:
  - 光照随时间变化，阴影方向与强弱同步变化。

- **状态**: 进行中（2026-05-27，已落地日照估计器 + Filament SUN 光动态更新 + 阴影参数质量档位）。
